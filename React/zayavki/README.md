# Доска заявок ИТ-отдела

Учебная доска по главам 1.1–1.7. Студент указывает кабинет, категорию и описание проблемы. Дежурный может раскрыть подробности, взять заявку в работу, завершить и убрать её с доски. При первом открытии видны пять примеров.

## Запуск

Из папки `React/zayavki` под Node.js 24 выполните:

```bash
npm ci
npm run dev
```

Откройте `http://localhost:5173`. Доски ИТ-отдела и общежития запускаются по очереди на одном порту. У каждой свой ключ в localStorage.

Новая заявка сохраняется в браузере до отправки POST на вебхук. Если n8n выключен, карточка остаётся на доске и после перезагрузки.

## Проверка

```bash
npm run build
npm run lint
```
