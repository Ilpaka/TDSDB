В модуле 4 собраны два связанных проекта. Утренний процесс готовит пересказы новостей, а сайт позволяет читать и фильтровать их. Вечерний процесс собирает ссылки за сутки в одно сообщение.

## Что проверено

- Первый опубликованный выпуск содержал 15 материалов за 19 ноября 2026 года. Поиск находит слова в заголовках и пересказах, его можно сочетать с тегом и флажком «Только непрочитанные». Отметки сохраняются после перезагрузки. Время публикации указано в МСК.
- Все семь тестов прошли. Линтер завершился без предупреждений, сборка прошла. На выпуске из 15 карточек Lighthouse показал доступность 100/100. Работа фильтров и кнопок проверена клавиатурой, на ширине 360 пикселей лента помещается в экран.
- n8n и локальная модель Qwen3 обработали по пять материалов из RSS Хабра, Naked Science и iXBT. В тестовом хранилище первый запрос добавил 15 строк, повторная запись тех же новостей — ноль. Запрос без ключа получил отказ. Вечерний процесс передал тестовому получателю сообщение на 2748 знаков.
- Пересказы первого выпуска сверены с текстами лент. У нескольких новостей исправлены теги, уточнён результат эксперимента по очистке воды. При первоначальном прогоне оба внешних сервиса заменяли локальные тестовые получатели.
- 20 ноября вечерний процесс n8n прочитал 15 новостей из опубликованного JSON на GitHub Pages и отправил их в личный Telegram-чат. Доставку подтвердил Telegram API.

## Проверка с Google Таблицей

20 ноября 2026 года утренний процесс n8n записал в таблицу по пять новостей из RSS Хабра, Naked Science и iXBT. При повторной записи того же пакета осталось 15 строк. Вечерний процесс прочитал лист и доставил в личный Telegram-чат сообщение «Дайджест за 20.11.2026: 15 новостей». Оба процесса проверены ручным запуском. Расписание в локальном n8n — 08:00 и 19:00 по Москве. Для работы по расписанию компьютер и Docker должны быть включены. Сайт получает данные напрямую из таблицы при открытии. [Публикация с подключённым источником](https://github.com/Ilpaka/digest/actions/runs/44619802101).

На снимках показан первый выпуск, отправленный из сохранённого файла. В заголовке сообщения указаны 15 новостей. На трёх снимках видны все ссылки из выпуска. Снимки сделаны после полуночи по Москве. В последующей версии процесса дата в заголовке вычисляется в московском часовом поясе.
