# Мониторинг сайтов на Angular

Практика главы 4.4. На главной странице пять сайтов группы, сводка и два фильтра. Введите «мониторинг», чтобы оставить две карточки. Нажатие на название открывает страницу сайта. Флажок «Только неработающие» показывает сайты, для которых последняя проверка зафиксировала сбой.

## Запуск

В папке `React/monitoring-ng` с Node.js 24 выполните `npm ci` и `npm start`, затем откройте адрес из терминала. Команда `npm test` запускает четыре теста страницы. Для сборки и проверки стиля выполните `npm run build` и `npm run lint`.

## Как связаны две версии

| Поведение | React | Angular |
|---|---|---|
| Загрузка двух файлов | Провайдер контекста и `fetch` | Служба `Monitoring` и `httpResource` |
| Поиск и флажок | `useState` и выборка при отрисовке | `signal` и `computed` |
| Открытие карточки | `Link` и параметр маршрута | `RouterLink` и `withComponentInputBinding` |

В `public/data` лежит снимок реальной проверки пяти сайтов 20 ноября 2026 года по московскому времени. Ночные результаты продолжает собирать опубликованный React-монитор. Четыре теста на фиксированном наборе данных проверяют сводку, переход по ссылке, поиск и пустой результат при сочетании поиска с флажком.
