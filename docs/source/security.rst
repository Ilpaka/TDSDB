Модель безопасности
===================

Полный текст требований — ``docs/standards/SECURITY_STANDARD.md``; результаты
проверки — ``docs/audit/OWASP_API_AUDIT.md``.

Аутентификация
--------------

1. Клиент вызывает ``POST /api/v1/auth/login`` с email и паролем.
2. Сервер проверяет bcrypt-хэш и выпускает JWT (HS256) со сроком действия
   ``ACCESS_TOKEN_EXPIRE_MINUTES`` (по умолчанию 60 минут).
3. Клиент передаёт токен в заголовке ``Authorization: Bearer <token>``.
4. Отсутствующий, повреждённый или просроченный токен — ``401`` с заголовком
   ``WWW-Authenticate: Bearer``; деактивированная учётная запись — ``403``.

Публичная регистрация отсутствует: пользователей создаёт администратор, а
первого администратора — скрипт ``scripts/create_admin.py``.

Роли
----

.. list-table::
   :header-rows: 1

   * - Роль
     - Права
   * - admin
     - Все операции, управление пользователями, журнал действий.
   * - manager
     - Создание проектов; управление своими проектами и доступом к ним.
   * - worker
     - Работа с документами в проектах с доступом ``editor``.
   * - viewer
     - Чтение проектов и документов в рамках выданного доступа.

Проверка роли — зависимость :func:`app.core.deps.require_roles`.

Доступ к объектам
-----------------

Каждая операция с ``{project_id}`` или ``{document_id}`` определяет уровень
доступа пользователя к проекту (:mod:`app.core.permissions`):
администратор и владелец — ``editor``, прочие — по записи ``ProjectAccess``.
Без доступа объект неотличим от несуществующего (``404``); при доступе
``viewer`` попытка изменения — ``403``.

Конфигурация
------------

* Секреты — только в переменных окружения / ``.env``.
* В ``production`` запуск блокируется при демонстрационном или коротком
  ``JWT_SECRET``, ``DEBUG=true`` или ``*`` в ``CORS_ORIGINS``.
* CORS разрешает только перечисленные origin.
* Ответы содержат ``X-Content-Type-Options``, ``X-Frame-Options``,
  ``Referrer-Policy``, ``Cache-Control: no-store``.

Ресурсные ограничения
---------------------

* Вход: не более 10 попыток за 60 секунд с одного адреса, далее ``429`` и
  ``Retry-After`` (:mod:`app.core.rate_limit`).
* Тело запроса: не более 1 МиБ, иначе ``413`` (:mod:`app.core.middleware`).
* Коллекции: ``limit`` ≤ 100; содержимое документа ≤ 100 000 символов.
