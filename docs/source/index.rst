Document Center API
===================

Техническая документация внутреннего REST API ИП «Северный Контур» для
управления документами по проектам.

* Базовый путь публичного контракта: ``/api/v1``
* Интерактивная документация: ``/docs`` (Swagger UI), ``/redoc`` (ReDoc)
* Формальный контракт: ``/openapi.json``, экспорт — ``docs/openapi/openapi.json``
