# Запросы к `hosting.servers`

Все фильтры вставляются в поле **Filter** в Compass как есть. Ожидаемое число — счётчик
документов в результате. Всего документов в коллекции: **5**.

## 1. Точное совпадение

Все выделенные серверы.

```js
{ type: "dedicated" }
```

Ожидается: **3** (`DED-SPB-001`, `DED-SPB-002`, `DED-MSK-003`).

## 2. Вложенное поле

Всё, что стоит в петербургской площадке.

```js
{ "location.city": "Санкт-Петербург" }
```

Ожидается: **2** (`DED-SPB-001`, `DED-SPB-002`).

## 3. Элемент массива

Серверы, у которых в тегах есть `nvme`. Для массива строк равенство означает
«хотя бы один элемент равен».

```js
{ tags: "nvme" }
```

Ожидается: **3** (`DED-SPB-001`, `DED-SPB-002`, `VPS-MSK-101`).
`VPS-AMS-201` в выдачу не попадает, хотя диск у него NVMe — поля `tags` у документа нет.

## 4. Сравнение

Всё дешевле 5000 ₽/мес.

```js
{ "price.monthly_rub": { $lt: 5000 } }
```

Ожидается: **2** (`VPS-MSK-101` — 690, `VPS-AMS-201` — 4200).

## 5. `$exists`

Серверы с видеокартой.

```js
{ "hardware.gpu": { $exists: true } }
```

Ожидается: **1** (`DED-SPB-002`).

Обратный вариант — карточки, у которых не проставлены теги:

```js
{ tags: { $exists: false } }
```

Ожидается: **1** (`VPS-AMS-201`).

## 6. Намеренно сломанный

```js
{ price.monthly_rub: { $lt: 5000 } }
```

Ожидается: **ошибка разбора**, результата нет вообще.

Это не пустая выборка, а невалидный синтаксис: ключ с точкой обязан быть в кавычках.
Compass подсвечивает поле красным и не отправляет запрос на сервер; в `mongosh` это
`SyntaxError`, потому что `price.monthly_rub` парсится как обращение к свойству
несуществующей переменной `price`, а не как имя ключа.

Для сравнения — тот же запрос с опечаткой в имени поля разбирается нормально, просто
ничего не находит:

```js
{ "price.monthly": { $lt: 5000 } }
```

Ожидается: **0**. Это уже пустой результат: сервер честно проверил все документы, но
поля `price.monthly` ни у кого нет. Разница принципиальная — первый случай ловится
до запроса, второй молча возвращает ноль, и в приложении такое можно не заметить.
